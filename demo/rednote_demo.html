How it reaches RedNote

RedNote has no public API. Scout talks to xpzouying/xiaohongshu-mcp, the most widely used RedNote MCP server. It runs a logged-in RedNote session in a headless browser and offers both MCP and a plain REST API. Scout calls three of its routes: /feeds/search, /feeds/detail and /login/status. No request-signing code lives in Scout, so when RedNote changes its web app, only the server needs updating.

  1. Run the server with a dedicated RedNote account, and log in once by scanning a QR code in the RedNote app: 
    curl -O https://raw.githubusercontent.com/xpzouying/xiaohongshu-mcp/main/docker/docker-compose.yml
docker compose up -d        # port 18060, cookies kept in ./data
  2. Point Scout at it in .env and run a scan: 
    REDNOTE_MCP_URL=http://localhost:18060
scout migrate && scout ingest --source rednote
  3. The Discord bot scans every 6 hours, /scan includes RedNote, kept notes can appear in the daily brief, and /rednote dexterous hands searches them.
  4. To replay this demo without an account, run make rednote-demo. It starts a stand-in server that speaks the same API and serves the sample notes.
